\# Sportsphere Hub



A comprehensive full-stack web application designed for sports facility management, court reservations, and sports equipment marketplace. 



\## Features

\* \*\*Role-Based Access Control:\*\* Distinct dashboards and functionalities for Athletes, Facility Workers, and Administrators.

\* \*\*Advanced Search \& Filtering:\*\* Dynamic, multi-criteria filtering for sports venues (by name, city, sport, and court type).

\* \*\*Booking System:\*\* Interactive calendar for scheduling training sessions and reserving specific courts.

\* \*\*Custom File Handling:\*\* Robust image upload mechanism featuring on-the-fly SVG avatar generation and conversion.

\* \*\*Automated Business Reporting:\*\* Dynamic PDF generation for facility occupancy statistics and equipment sales using `jsPDF`.



\##  Tech Stack

\* \*\*Frontend:\*\* Angular, TypeScript, HTML/CSS

\* \*\*Backend:\*\* Node.js, Express.js

\* \*\*Database:\*\* MongoDB, Mongoose

\* \*\*Tools/Libraries:\*\* Multer (file uploads), jsPDF \& autoTable (reports), DiceBear API (avatars)



\##  Setup and Installation

1\. Clone the repository: `git clone https://github.com/tvoj-username/sportsphere-hub.git`

2\. Install backend dependencies: `cd backend \&\& npm install`

3\. Install frontend dependencies: `cd frontend \&\& npm install`

4\. Start the backend server: `npm start`

5\. Start the Angular application: `ng serve`
